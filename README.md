# JuiceBot

## What is this ?
This is JuiceBot, a Discord bot made for the [JUICE Discord server](https://discord.gg/V5zzqTdrwT). It features categories FAQ, moderation utils, spambot prevention and more.

## What is JUICE ?
JUICE stands for **J**ava **U**noff**I**cial **C**ategory **E**xtensions. It is a [speedrun.com minecraft leaderboard](https://www.speedrun.com/mc_juice) that handles non-official category extensions, like Break Beenest, All Buckets or Fishtank.
